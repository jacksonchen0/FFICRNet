# FFICRNet
Low-Light Light Field Image Enhancement via Frequency Feature Interaction and Contrastive Regularization

## Environment
- Python: 3.8 ~ 3.10
- PyTorch: 1.12.1 / 2.0.1
- CUDA: 11.3 / 11.7
- pip install torch torchvision einops numpy scipy opencv-python h5py tqdm

## Train
python train.py

## test
python test.py
